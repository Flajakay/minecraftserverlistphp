# Minecraft Server List (WiP)

A modern PHP-based Minecraft server listing platform built with Bootstrap 5 and PHP 8.0. This is a complete recreation of the original minecraftserverlistphp project with improved architecture and better design.




**MANY FEATURES FROM THE LIST BELOW ARE YET TO BE IMPLEMENTED**



## Features

- **Server Management**: Submit, edit, and manage Minecraft servers
- **Real-time Server Status**: Automatic server pinging and status updates
- **User System**: Registration, login, profiles with social features
- **Voting System**: Daily voting with Votifier integration
- **Favorites**: Save favorite servers for easy access
- **Categories**: Organize servers by type (Survival, Creative, PvP, etc.)
- **Premium Features**: Server highlighting and featured placement 
- **Admin Panel**: Complete administration interface 
- **Responsive Design**: Mobile-friendly Bootstrap 5 interface 
- **Search & Filters**: Advanced filtering by status, country, version, etc. 

## Requirements

- PHP 8.0 or higher (+ GD, sockets, curl, pdo_mysql)
- MySQL 5.7+

## Installation

1. **Download and Extract**
   ```bash
   # Extract files to your web directory
   # Example: /var/www/html/minecraft-servers/
   ```
2. **Run Installation**
   - Run composer install
   - Navigate to `your-domain.com/`
   - Fill in database and site configuration
   - Click Install

3. **Post-Installation**
   - Delete / rename `install.php`
   - Login with default admin account: `admin/admin`
   - Change admin password immediately
   - Configure site settings in admin panel
